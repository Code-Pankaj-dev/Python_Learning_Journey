                      DATA TYPES IN PYTHON
                      ====================
    Python has several built-in data types. They define the type of value a variable holds.

      |--------|---------------------|-------------------------------------------|
      | Type   |    Example          |            Description                    |
      |--------|---------------------|-------------------------------------------|
      |int     |  x = 10             |     While number (positive or negative)   |
      |--------|---------------------|-------------------------------------------|
      | float  |  y = 3.145          |     Number the Decimals                   |
      |--------|---------------------|-------------------------------------------|
      | str    |  name = "ranjeet"   |     Sequence of characters                |
      |--------|---------------------|-------------------------------------------|
      | bool   |  flag = True        |     Logical value: True or False          |
      |--------|---------------------|-------------------------------------------|

    NOTE: Use the type() function to check a variable's data type.
    Example:
            x = 10 
            print(type(x))
               Output: 
                     <class "int">

    TYPE CONVERSIONS
    ================
        Type conversion means changing one data type to another.
      A.  IMPLICIT CONVERSIONS (AUTOMETIC)
          Python automatically converts smaller data types to larger ones to prevent data loss.
           
           x = 10  # int
           y = 15.7 #float
           z = x+y # Python converts int ------->  float
           print(z)  # 25.7
        
      B.  Explicit conversion (Manual)
          Manually convert data types using built-in function:

          x = "10"
          y = int(x)    #str--->int
          print(y+5)    #Output: 15
        
       COMMON FUNCTIONS: 
            int(), float(), str(), bool()

    OPERATORS IN PYTHON:
    ====================
       Operators perform operations on variable and values.

    |-------------|-----------------|---------------------------------------|
    |   TYPE      |    EXAMPLE      |        DISCRIPTION                    |
    |-------------|-----------------|---------------------------------------|
    | Arithmetic  | + - * / % **    | Math operations(** for power)         |
    |-------------|-----------------|---------------------------------------|
    | Comparison  | == != > < >= <= | Compare values, returns True or False |
    |-------------|-----------------|---------------------------------------|
    |  Logical    | and or not      |   Combine Conditions                  |
    |-------------|-----------------|---------------------------------------|
    |Assignment   | = += -= *= /=   | Assign or Modify values               |
    |-------------|-----------------|---------------------------------------|

    Example: 
      x = 5 
      y = 5
      print(x+y) #10
      print(x>y) #True
      print(x > 0 and y < 20) # True (Both Conditions are True)
