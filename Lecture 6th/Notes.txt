# 1. Introduction to Loops

In Python, **loops** are used to repeat a block of code multiple times.

They help perform tasks such as:

* Printing a message multiple times
* Iterating over lists, tuples, and strings
* Generating patterns
* Performing repetitive calculations

### Example Without a Loop

```python
print("Pankaj Upadhyay")
print("Pankaj Upadhyay")
print("Pankaj Upadhyay")
print("Pankaj Upadhyay")
print("Pankaj Upadhyay")
```

Instead of writing the same code five times, we can use a loop.

---

# 2. While Loop

A **while loop** repeatedly executes a block of code as long as a given condition is `True`.

### Syntax

```python
while condition:
    # code block
```

### Example

```python
i = 1

while i <= 5:
    print("Pankaj Upadhyay")
    i = i + 1
```

### Output

```text
Pankaj Upadhyay
Pankaj Upadhyay
Pankaj Upadhyay
Pankaj Upadhyay
Pankaj Upadhyay
```

### Important

The statement:

```python
i = i + 1
```

updates the value of `i` after every iteration.

We can also write:

```python
i += 1
```

If we forget to update `i`, the loop may become an **infinite loop**.

# 3. For Loop

A **for loop** is used to iterate over an iterable such as a list, tuple, string, or range.

### Syntax

```python
for element in sequence:
    # code block
```

### Example

```python
foods = ["Pizza", "Burger", "Samosa", "Pakoda"]

for item in foods:
    print("Pankaj likes:", item)
```

### Output

```text
Pankaj likes: Pizza
Pankaj likes: Burger
Pankaj likes: Samosa
Pankaj likes: Pakoda
```

---

# For Loop with `range()`

The `range()` function generates a sequence of numbers and is commonly used with loops.

### Syntax

```python
range(start, stop, step)
```

### Parameters

* **start** → Starting number. Default is `0`.
* **stop** → Ending limit. This value is **excluded**.
* **step** → Difference between numbers. Default is `1`.

### Example

```python
for i in range(1, 6):
    print("Iteration:", i)
```

### Output

```text
Iteration: 1
Iteration: 2
Iteration: 3
Iteration: 4
Iteration: 5
```

Notice that `6` is not included because the `stop` value is excluded.

# 4. `break`, `continue`, and `pass`

## A. `break` Statement

The `break` statement **stops the loop immediately** when it is encountered.

### Example

```python
for num in range(1, 10):
    if num == 5:
        break
    print(num)
```

### Output

```text
1
2
3
4
```

The loop stops when `num == 5`.

> `5` is not printed because `break` executes before `print(num)`.

---

# B. `continue` Statement

The `continue` statement **skips the current iteration** and moves to the next iteration of the loop.

### Example

```python
for num in range(1, 6):
    if num == 3:
        continue
    print(num)
```

### Output

```text
1
2
4
5
```

Here, `3` is skipped.

### Practice Question

# C. `pass` Statement

The `pass` statement does nothing.

It is used as a **placeholder** when a block of code is intentionally left empty.

### Example

```python
for i in range(5):
    pass
```

The loop runs, but `pass` does not perform any operation.

# 5. Nested Loops

A **loop inside another loop** is called a nested loop.

### Example

```python
for i in range(1, 4):
    for j in range(1, 4):
        print(i, j)
```

### Output

```text
1 1
1 2
1 3
2 1
2 2
2 3
3 1
3 2
3 3
```

Here:

* The outer loop controls `i`.
* The inner loop controls `j`.
* For every value of `i`, the inner loop runs completely.

---

# Nested Loop Practice

Write a program using nested loops to print the following pattern:

```text
*
* *
* * *
```

### Example Solution

```python
for i in range(1, 4):
    for j in range(i):
        print("*", end=" ")
    print()
```

### Output

```text
*
* *
* * *
```

# 6. Mini Project — Countdown Timer

### Goal

Print a countdown before something exciting happens, such as:

* Launching
* Happy New Year
* Starting an event

### Concepts Used

* `for` loop
* `range()`
* `time` module

### Example

```python
import time

for i in range(5, 0, -1):
    print(i)
    time.sleep(1)

print("Launching...")
```

### Output

```text
5
4
3
2
1
Launching...
```

There is a **1-second gap** between each number.

# 8. Mini Project — Guess the Number Game

### Goal

Create a simple game where the user tries to guess a randomly generated number between `1` and `10`.

### Concepts Used

* `while` loop
* `input()`
* Type conversion
* `if-else`
* `break`
* `random` module

### Code

```python
import random

number = random.randint(1, 10)

while True:
    guess = int(input("Guess a number between 1 and 10: "))

    if guess == number:
        print("Congratulations Dev! You guessed it right.")
        break
    else:
        print("Wrong guess! Try again.")
```

### Sample Run

```text
Guess a number between 1 and 10: 4
Wrong guess! Try again.

Guess a number between 1 and 10: 7
Congratulations Dev! You guessed it right.
```

The actual correct number will be different each time because it is generated randomly.
