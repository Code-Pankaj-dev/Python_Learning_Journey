1. Introduction to loop:
------------------------
     In Python, loops are used to repeat a block of code multiple time.

     They help performs tasks like printing a message several times, iterating over lists, or generating patterns.

    Example:
       print("Pankaj Upadhyay")
       print("Pankaj Upadhyay")
       print("Pankaj Upadhyay")
       print("Pankaj Upadhyay")
       print("Pankaj Upadhyay")

    Insted of writing this three times, we can use a loop.

2. while loop:
---------------
      A while loop runs as long as a condition is True.
    Syntex:
    -------:    while condition:
                   # code block

    Example:
    --------
           i = 1
           while i<=5:
               print("Pankaj Upadhyay")
             #  i+=1 
               i= i+1  

    Output:
    ------:
            Pankaj Upadhyay
            Pankaj Upadhyay
            Pankaj Upadhyay
            Pankaj Upadhyay
            Pankaj Upadhyay

3. for loop
-----------
     A for loop is used to iterate (go through) sequence like lists, tuples, or strings.
    Syntex:
    ------:
         for element in sequence:
              # code block
    Example:
    -------:
          foods = ["Pizza", "Burger", "Samosha", "Pakuda"]
          for item in foods:
              print("Pankaj likes: ", item)
    Output:
    ------:
           Pankaj likes: Pizza
           Pankaj likes: Burger
           Pankaj likes: Samosha
           Pankaj likes: Pakuda

    for loop with range():
    ---------------------:
         The range function is generates a sequence of numbers.
         It is often used with loops.

    Syntex:
    ------: 
    
       range(start, stop, step)
         * start--> begining number (default = 0)
         * stop --> end limit (excluded)
         * step --> increment value (default = 1)
        
    Example:
    -------: 
    for i in range(1, 6):
    print("Iteration:",i)

    Output:
    ------:
          Iteration: 1
          Iteration: 2
          Iteration: 3
          Iteration: 4 
          Iteration: 5

4. break, continue and pass:
---------------------------:
    break Statement:
    ---------------:
                    The break Statement stops the loop immediately when it is encountered.
        Example:
        -------:   for num in range(1, 10):
                      if num == 5;
                         break
                      print(num)

        Output: 
              1.
              2.
              3.
              4.
        
        (loop stops when num == 5)
        Output:
              1.
              2.
              3.
              4.
              5.
    pass Statement:
    --------------:
          The pass Statement does nothing -- It's used as a placeholder when you want to keep a block empty:
        Example:
           for i in range(5):
           pass # future code will go here.

5. Nested Loops:
---------------:
    A loop inside another loop is called a nested loop.
    Example:
        for i in range(1,4 ):
           for  j in range(1,4): 
               print(i,j)

    Output:
        1 1 
        1 2 
        1 3 
        2 1 
        2 2 
        2 3 
        3 1 
        3 2
        3 3
