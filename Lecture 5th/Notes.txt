# 1. Dictionary in Python

A **Dictionary** is a built-in Python data type used to store data in **key-value pairs**.

### Key Features

* A dictionary stores data in **key-value pairs**.
* Each key must be **unique**.
* Values can be duplicated.
* Dictionaries are **mutable**, which means their contents can be changed.
* Dictionaries **preserve insertion order** in modern Python (Python 3.7+).
* Dictionary keys must be **hashable**, such as strings, numbers, or tuples containing hashable values.

### Example

```python
student = {
    "name": "Pankaj Upadhyay",
    "age": 21,
    "city": "Siddharth Nagar",
    "college": "MMIT Bansi Siddharth Nagar",
    "rollnumber": 31
}
```

### Keys

```text
"name"
"age"
"city"
"college"
"rollnumber"
```

### Values

```text
"Pankaj Upadhyay"
21
"Siddharth Nagar"
"MMIT Bansi Siddharth Nagar"
31
```

---

## Accessing Dictionary Values

We can access a value using its key.

```python
print(student["name"])
print(student["city"])
print(student["college"])
```

### Output

```text
Pankaj Upadhyay
Siddharth Nagar
MMIT Bansi Siddharth Nagar
```

> If the specified key does not exist, `student["key"]` raises a `KeyError`.

---

# Adding and Updating Items

If a key does not exist, assigning a value creates a new key.

```python
student["email"] = "pankaj@example.com"
```

If the key already exists, its value is updated.

```python
student["rollnumber"] = 21
student["college"] = "BTEUP Lucknow"

print(student)
```

---

# Removing an Item

The `pop()` method removes the specified key and returns its value.

```python
student.pop("city")
print(student)
```

---

# Important Dictionary Methods

| Method         | Description                                   |
| -------------- | --------------------------------------------- |
| `keys()`       | Returns all keys                              |
| `values()`     | Returns all values                            |
| `items()`      | Returns all key-value pairs                   |
| `get(key)`     | Returns the value for a key safely            |
| `update(dict)` | Adds or updates items from another dictionary |
| `pop(key)`     | Removes the specified key                     |
| `clear()`      | Removes all items                             |

### Examples

```python
print(student.keys())
print(student.values())
print(student.items())
print(student.get("name"))
```

### `update()` Example

```python
student.update({"city": "Lucknow"})
print(student)
```

> **Important:** Dictionary uses `:` between key and value, not `=`.

Correct:

```python
{"city": "Lucknow"}
```

Incorrect:

```python
{"city" = "Lucknow"}
```

---

# Nested Dictionary

A dictionary can contain another dictionary as a value.

```python
profile = {
    "username": "dev_verse",
    "details": {
        "followers": 1300,
        "verified": True
    }
}

print(profile["details"]["followers"])
```

### Output

```text
1300
```

# 2. Set in Python

A **Set** is an unordered collection of **unique elements**.

A set automatically removes duplicate elements.

### Example

```python
languages = {"Python", "Java", "C++", "Python"}

print(languages)
```

The duplicate `"Python"` is automatically removed.

### Possible Output

```text
{'Python', 'Java', 'C++'}
```

> The order of elements in a set is **not guaranteed**, so the output order may be different.

---

# Creating a Set

```python
empty_set = set()

nums = {1, 2, 3, 4}
```

### Important

Do not use `{}` to create an empty set.

```python
empty = {}
```

This creates an **empty dictionary**, not a set.

Correct:

```python
empty_set = set()
```

---

# Properties of a Set

### 1. Unique

A set does not store duplicate elements.

```python
nums = {1, 2, 2, 3}
print(nums)
```

Output:

```text
{1, 2, 3}
```

### 2. Unordered

A set does not provide a fixed positional order.

### 3. Mutable

We can add or remove elements from a set.

### 4. No Indexing

We cannot access set elements using indexes like:

```python
nums[0]
```

This results in an error.

### 5. Set Elements Must Be Hashable

A set cannot directly contain mutable objects such as lists or dictionaries.

---

# Adding and Removing Elements

```python
nums = {1, 2, 3, 4, 5}

nums.add(6)
nums.remove(3)

print(nums)
```

The set will contain:

```text
{1, 2, 4, 5, 6}
```

> The order may vary because sets are unordered.

---

# Important Set Methods

| Method               | Description                                           |
| -------------------- | ----------------------------------------------------- |
| `add(element)`       | Adds an element                                       |
| `remove(element)`    | Removes an element; raises `KeyError` if not found    |
| `discard(element)`   | Removes an element without raising an error if absent |
| `clear()`            | Removes all elements                                  |
| `pop()`              | Removes and returns an arbitrary element              |
| `union(set2)`        | Combines elements from both sets                      |
| `intersection(set2)` | Returns common elements                               |

---

# Union Example

```python
set1 = {1, 2, 3}
set2 = {3, 4, 5}

result = set1.union(set2)

print(result)
```

Output:

```text
{1, 2, 3, 4, 5}
```

---

# Intersection Example

```python
set1 = {1, 2, 3}
set2 = {3, 4, 5}

result = set1.intersection(set2)

print(result)
```

Output:

```text
{3}
```

# 3. Difference Between Dictionary and Set

| Feature                 | Dictionary                | Set                     |
| ----------------------- | ------------------------- | ----------------------- |
| Structure               | Key-value pairs           | Unique values           |
| Syntax                  | `{"key": value}`          | `{value1, value2}`      |
| Mutable                 | Yes                       | Yes                     |
| Duplicate Keys/Elements | Keys must be unique       | Elements must be unique |
| Indexing                | No                        | No                      |
| Ordering                | Preserves insertion order | No guaranteed order     |
| Main Use                | Store data with keys      | Store unique elements   |

### Example

**Dictionary:**

```python
student = {
    "name": "Pankaj",
    "age": 21
}
```

**Set:**

```python
numbers = {1, 2, 3, 4}
```

### Question 3

Add both `9` and `9.0` to a set and observe the result.

```python
numbers = {9, 9.0}

print(numbers)
print(len(numbers))
```

### Expected Result

```text
{9}
1
```

This happens because:

```python
9 == 9.0
```

is `True`, and they are treated as the same set element.

If you want them to be separate, use different types such as:

```python
numbers = {9, "9.0"}
```

Now they are different elements.
